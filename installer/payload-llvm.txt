# Toolchain files of the installed product: globs relative to third_party\llvm, "/" separated (INS-002).
# A glob that matches nothing fails the build; the end-to-end tests of the installed product (EndToEndTests) compile,
# link, compile resources and debug with exactly these files, so a file they need and the list leaves out fails them.

# compiler back end (CMP-600): clang compiles the emitted IR, lld-link links, llvm-dlltool writes import libraries
bin/clang.exe
bin/lld-link.exe
bin/llvm-dlltool.exe
# resource compiler (prc): llvm-rc, preprocessing through clang
bin/llvm-rc.exe
# debugger: the adapter and its library (liblldb loads the Python runtime of payload-third-party.txt). The scripting
# module of the debugger (lib/site-packages/lldb, with a second copy of the library) is not shipped: the adapter does
# not load it, and a debug session (breakpoint, call stack, arguments and locals, run to the end) works without it.
bin/lldb-dap.exe
bin/liblldb.dll
